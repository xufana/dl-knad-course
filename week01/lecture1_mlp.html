Постановка задачи: ничего нового

Выборка, параметрическая модель, функция потерь, оптимизация. Единственное требование, которое всё определит дальше, — дифференцируемость.

Есть обучающая выборка {(xi, yi)}ℓi=1, xi ∈ ℝd. Есть модель f(x, w) с параметрами w ∈ W. Есть функция потерь L(ŷ, y), которая говорит, насколько плох ответ модели на одном объекте. Цель — минимизировать средние потери по выборке, эмпирический риск:

Q(w) = 1ℓ Σi=1..ℓ L(f(xi, w), yi) → minw

Оптимизируем градиентным спуском: w ← w − η ∇wQ(w). Значит, и f, и L должны быть дифференцируемы по w.

Для линейной модели f(x, w) = ⟨w, x⟩ градиент выписывается руками.

Напоминание: градиент линейной модели

Регрессия с квадратичной потерей L(ŷ, y) = (ŷ − y)2:

Q(w) = 1ℓ Σi (⟨w, xi⟩ − yi)2,     ∇wQ = 2ℓ Σi (⟨w, xi⟩ − yi) · xi

То есть градиент — сумма объектов xi, каждый с весом «насколько ошиблись на нём». Для логистической регрессии с log-loss формула та же, только ошибка — σ(⟨w, xi⟩) − yi. На трёх объектах, с редактируемым w:

объектxiyi⟨w, xi⟩ошибка riri · xi

Главный технический вопрос занятия: как посчитать ∇wQ, когда f — композиция десятков функций с миллионами параметров?

Что даёт и чего не даёт градиентный спуск

  • Шаг вдоль антиградиента уменьшает Q — при достаточно маленьком η.
  • Слишком большой η — расходимся; слишком маленький — стоим на месте.
  • Невыпуклая Q — сходимся в ближайший локальный минимум, какой достанется. У нейросетей Q всегда невыпуклая.
  • Всё, что нужно от модели, — уметь считать значение и градиент. Больше ничего.
Вопрос в зал: почему нельзя обучать по метрике, например по доле правильных ответов?

Потолок линейной модели

Линейный классификатор проводит одну гиперплоскость в тех признаках, которые ему дали. Признаки можно придумать руками или взять ядро — но тогда их выбираем мы. Сколько бы линейных слоёв мы ни поставили друг на друга, ничего нового они не выучат: их композиция — всё та же одна гиперплоскость.

Возьмём x ∈ ℝd и построим «глубокую» модель из линейных слоёв:

z1 = W1xz2 = W2z1…zn = Wnzn−1

где Wi ∈ ℝdi×di−1. Тогда zn = Wn…W2W1x = Wx, где W ∈ ℝdn×d — одна матрица. Сто линейных слоёв — это ровно один линейный слой, только дороже. Смещения ничего не меняют: композиция аффинных отображений аффинна.

Значит, чтобы получить что-то новое, между слоями нужно поставить нелинейность. Это единственная причина, по которой в нейросетях есть функции активации.

Где линейная модель ломается

XOR — классический пример: четыре облака, каждый класс по диагонали. Никакая прямая не отделит их. Кольца, спираль — то же самое. В интерактиве ниже: сначала обучите линейную модель и убедитесь, что граница — прямая, потом добавьте слоёв без активации, потом включите активацию.

Вопрос в зал: линейная модель на XOR даёт около 50 % точности. Можно ли починить её без нейросети? Да: руками добавить признак x1x2. Нейросеть — способ не придумывать такие признаки руками.

Нейрон, слой, MLP

Слой — аффинное преобразование плюс поэлементная нелинейность. Сеть — несколько таких слоёв подряд. Вся «магия» — в том, что скрытые нейроны выучивают признаки, которые раньше пришлось бы придумывать руками.

ui = Wizi−1 + bizi = σ(ui)
  • Wi ∈ ℝdi×di−1 — веса, bi ∈ ℝdi — смещения. Обучаются и те и другие. Смещение превращает линейное отображение в аффинное: без него все границы проходили бы через ноль.
  • σ: ℝ → ℝ — скалярная нелинейность, применяется к каждой координате ui отдельно.
  • zi — скрытое (латентное) представление объекта после i-го слоя. Каждая координата — один нейрон.
  • Число параметров слоя: di·di−1 + di. Слой 784 → 256 — это уже 200 тысяч чисел.

Такой слой называют полносвязным (fully-connected, dense): каждый нейрон связан с каждым нейроном предыдущего слоя. Сеть из таких слоёв — многослойный перцептрон (MLP) или полносвязная сеть (FCN). Последний слой обычно без активации или с активацией под задачу: sigmoid для бинарной классификации, softmax для многоклассовой, ничего для регрессии.

Что «видит» скрытый нейрон

Для двумерного входа нейрон первого слоя считает σ(w1x1 + w2x2 + b). Линия w1x1 + w2x2 + b = 0 делит плоскость пополам; с одной стороны нейрон «горит», с другой — нет. Каждый нейрон — одна полуплоскость. Следующий слой складывает полуплоскости с весами — и получаются углы, полосы, кольца.

Именно это видно в галерее ниже: у сети, обученной на XOR, скрытые нейроны становятся диагональными полуплоскостями, а выходной слой собирает из них «шахматную доску».

Вопрос в зал: сколько нейронов в одном скрытом слое нужно для XOR? Двух достаточно: две полуплоскости, выход считает их разность. Для кольца — три-четыре; для спирали одного слоя мало практически.

Как получить градиент: chain rule

Нейросеть — композиция функций. Производная композиции — произведение производных. Осталось понять, как это организовать, чтобы не считать миллион раз одно и то же.

Скалярный случай. Если y = f(g(x)), то

dydx = dfdg · dgdx

Несколько путей. Если y = f(g1(x), …, gn(x)), вклады всех путей от x к y складываются:

dydx = Σi=1..n ∂f∂gi · dgidx

Это частные производные f по своим аргументам, а не полные. Всё, что делает backpropagation, — применяет эти две формулы к графу вычислений в правильном порядке.

Напоминание. Частная производная ∂f/∂gi — производная f как функции нескольких аргументов по одному из них при остальных зафиксированных: она не знает, что все gi зависят от одного x. Полная производная dy/dx учитывает все зависимости сразу — это и есть сумма по путям выше. В графе на каждом ребре стоит частная производная, а полная собирается из них суммированием.

Три способа дифференцировать

  • Символическое. Из выражения x2 получаем выражение 2x, для всех x сразу. Для сети из сотни слоёв выражение разрастается экспоненциально; нам оно и не нужно.
  • Численное. (f(x + h) − f(x)) / h. Просто, но приближённо, и на каждый параметр нужен отдельный прогон сети: миллион параметров — миллион прямых проходов на один шаг. Годится только для проверки.
  • Автоматическое. Нам нужно не выражение, а число — значение градиента в текущей точке w. Считаем его точно, по цепному правилу, переиспользуя уже вычисленные значения. Один прямой и один обратный проход на все параметры сразу.

Вычислительный граф и backpropagation

Любое вычисление раскладывается в граф из простых операций. Прямой проход считает значения от входов к выходу; обратный — производные от выхода к входам, переиспользуя значения прямого.

Пример из конспекта: f(x1, x2, x3) = x12(x2x3 − 2x12). Разложим в граф:

z1 = x12z2 = x2 · x3z3 = 2 · z1z4 = z2 − z3y = z1 · z4

В каждом узле — своя элементарная операция с известной локальной производной. Обратный проход идёт по узлам в порядке, обратном прямому: для узла z уже известно dy/dz, и оно передаётся каждому входу, умноженное на локальную производную. Если в узел ведёт несколько путей — вклады складываются. Так у z1: один путь напрямую в y, второй через z3.

forwardbackward
Наблюдение 1 — память
Обратному проходу нужны z1, z4, x1, x2, x3 — значения, посчитанные на прямом. Их приходится хранить до конца обратного прохода. В реальной сети это активации всех слоёв на всём батче: именно они, а не веса, занимают память при обучении.
Наблюдение 2 — стоимость
Каждое ребро графа обрабатывается один раз на прямом и один раз на обратном проходе. Градиент по всем входам стоит примерно столько же, сколько одно вычисление функции, — а не в d раз дороже, как у численного метода. В этом весь смысл backprop.

Backprop через слои сети

Сеть — тот же граф, только узлы — слои, а рёбра — векторы. Формула та же, что на прошлом шаге; новое в ней одно — множитель σ′(ui) на каждом слое.

Запишем сеть как цепочку: z1 = f1(x; W1), z2 = f2(z1; W2), …, y = fn(zn−1; Wn), и потеря L(y). У каждого узла два входа: активации с предыдущего слоя zi−1 и собственные параметры Wi. Обратный проход отдаёт градиент по обоим:

∂L∂Wi = ∂L∂zi · ∂zi∂Wi,     ∂L∂zi−1 = ∂L∂zi · ∂zi∂zi−1

Первое — градиент по параметрам, он уходит в оптимизатор. Второе — то, что передаётся дальше назад. Для полносвязного слоя ui = Wizi−1 + bi, zi = σ(ui) обе локальные производные выписываются явно. Обозначим δi = ∂L/∂ui = ∂L/∂zi ⊙ σ′(ui), тогда:

∂L∂Wi = δi zi−1⊤∂L∂bi = δi∂L∂zi−1 = Wi⊤ δi

Матрица Wi появляется в двух ролях, и это не путаница. В первой формуле по ней дифференцируем — это градиент, который изменит веса. В третьей она стоит внутри производной как коэффициент: ui линейна по zi−1, поэтому ∂ui/∂zi−1 = Wi, и градиент, идущий назад, умножается на транспонированную матрицу текущих весов. Одна и та же матрица: по ней считаем шаг и через неё пропускаем сигнал.

Каждый слой умножает градиент на σ′(ui) и на Wi⊤. Через k слоёв — произведение k таких множителей. Если они систематически меньше единицы, градиент затухает экспоненциально с глубиной; если больше — взрывается.

Вопрос в зал: где в этой схеме нужна память, а где — вычисления? Память: все zi и ui на батч. Вычисления: обратный проход примерно вдвое дороже прямого — два матричных умножения на слой вместо одного.

Функции активации и затухающие градиенты

Множитель σ′(u) появляется на каждом слое. Какой он — решает, дойдёт ли сигнал обучения до первых слоёв.

Sigmoid

σ(x) = 11 + e−x,    σ′(x) = σ(x)(1 − σ(x)) ≤ ¼

Историческая активация: гладкая, выход в (0, 1), интерпретируется как вероятность. Но производная не больше 0.25, а вдали от нуля — практически ноль (насыщение). Через десять слоёв градиент умножится на число не больше 0.2510 ≈ 10−6. Это и есть затухание градиента: последние слои учатся, первые стоят.

tanh

Та же форма, но выход в (−1, 1), центрирован, максимум производной равен 1. Насыщается точно так же, но затухает медленнее — поэтому в маленьких сетях работает заметно лучше sigmoid.

ReLU

ReLU(x) = max(0, x),    ReLU′(x) = [x > 0]

Как дифференцировать max. max(0, x) — это x при x > 0 и 0 при x < 0, поэтому производная 1 или 0. В самой точке 0 производной нет, есть субградиент — любое число из [0, 1]; фреймворки берут 0. То же для max(a, b) вообще: градиент целиком уходит в тот аргумент, который победил, — так работает и max-pooling.

Производная либо 0, либо 1 — множитель не затухает, пока нейрон активен. В нуле функция не дифференцируема, и это не проблема: вероятность попасть ровно в ноль нулевая, берём любое значение из [0, 1]. Дёшево считается. Проблема другая — мёртвые нейроны: если нейрон ушёл в отрицательную область на всех объектах, его градиент тождественно ноль, и обратно он уже не вернётся.

Leaky ReLU

LeakyReLU(x) = max(αx, x),    α ≈ 0.01…0.2

Маленький наклон в отрицательной области — градиент никогда не ноль ровно, нейроны не умирают. Дальше по тому же пути — ELU, GELU, SiLU: гладкие варианты ReLU, стандарт в трансформерах. Идея всех — производная около 1 на большей части области.

Активации и произведение производных

Слева — σ и σ′ для выбранной активации. Справа — во сколько раз в среднем уменьшается норма градиента через k слоёв за счёт одних только активаций: на каждом слое множитель √E[σ′(u)2] при преактивациях u ~ N(0, s2), веса не учитываются. Все четыре активации на одном графике.

Sigmoid: множитель около 0.2 на слой — к десятому слою семь порядков. Tanh при большом разбросе преактиваций насыщается и тоже уходит вниз. ReLU даёт √½ на слой, потому что половина нейронов выключена, — именно это компенсирует He-инициализация, удваивая дисперсию весов. Leaky ReLU чуть лучше ReLU. Множители от весов Wi⊤ сюда не входят — их масштаб задаёт инициализация.

Вопрос в зал: если ReLU так хорош, почему в выходном слое всё равно sigmoid или softmax? Потому что выход должен быть вероятностью: активация выходного слоя выбирается под лосс, а не под градиент.

Есть ли жизнь без backprop

Backprop не единственный способ обучать сети — но единственный, который масштабируется. Полезно знать альтернативы, чтобы понимать, чем он хорош.

1950-е — сейчасЭволюционные алгоритмыМутируем веса, оставляем лучших. Градиент не нужен — но каждая «особь» стоит полного прогона, и в пространстве из миллиона параметров случайный поиск безнадёжен.
2000-еReservoir computingБольшая рекуррентная сеть со случайными фиксированными весами; обучается только линейный выходной слой. Работает на некоторых временных рядах; признаки не адаптируются к задаче.
2016Direct Feedback AlignmentВместо W⊤ на обратном проходе — случайная фиксированная матрица. Удивительно, что вообще учится; заметно хуже backprop на глубоких сетях.
2022Forward-Forward (Hinton)Два прямых прохода — на «хороших» и «плохих» данных, каждый слой учится локально. Не нужно хранить активации; пока сильно уступает по качеству.

Почему все всё равно используют backprop: точный градиент по всем параметрам за один обратный проход, стоимостью порядка прямого. Ни один из вариантов выше не даёт этого одновременно.

Итог

Три ответа на вопрос из начала занятия.

  1. Нелинейность даёт выразительность. Стек линейных слоёв — одна прямая. Один нелинейный слой из двух нейронов решает XOR; несколько слоёв выучивают признаки, которые иначе пришлось бы придумывать.
  2. Backprop делает обучение дешёвым. Градиент по миллиону параметров — один обратный проход по графу за цену примерно одного прямого. Плата — хранить весь прямой проход.
  3. Активация решает, дойдёт ли градиент. На каждом слое множитель σ′(u). Sigmoid его гасит, ReLU сохраняет, но может выключать нейроны насовсем.

Что дальше

Мы умеем считать градиент. Следующие вопросы — как им пользоваться:

  • напоминание про градиентный спуск и его варианты: стохастический градиент, momentum, Adam;
  • инициализация весов: как выбрать масштаб, чтобы градиент не затухал и не взрывался с первого шага;
  • регуляризация и нормализация — dropout, batch norm;
  • что, кроме полносвязных слоёв, бывает в графе: свёртки, attention.
